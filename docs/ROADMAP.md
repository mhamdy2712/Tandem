# Roadmap

Where Tandem is going. This is a plan, not a promise: items can move or change.

## Next
- **Code signing.** Sign the Windows installer so SmartScreen stops warning, and publish reputation-building releases.
- **Control the phone from the PC.** Tap, swipe and type on the phone's screen from the PC. It needs Android's Accessibility service, which Google Play Protect blocks for apps installed from a file. A way to offer it without breaking normal installs is being worked on.
- **Phone notifications on the PC.** Mirror notifications with reply and dismiss. Same Android restriction as above.
- **Chat that waits.** Send a file while the other device is off and have it delivered when they meet.

## Later
- **Google Play release**, so installs need no warnings.
- **Higher quality PC screen on Wi-Fi** (a quality selector) and better recovery on weak networks.
- **Bigger transfers**: resume an interrupted file transfer.
- **Pictures and files from the camera roll** straight into the chat with previews.
- **Self-hosted relay** guide for people who prefer to run their own.

## Being considered
- Linux and macOS for the PC side.
- iPhone support.
- Scheduling and automations (for example "when I get home, wake the PC").
